MODO NAVEGADOR LOCAL — MAGAZINE LUIZA / MAGALU

Por que existe:
O GitHub Codespaces pode receber HTTP 403 do Magalu mesmo quando a página abre

normalmente no navegador do seu computador. Este modo NÃO tenta contornar o
bloqueio do Codespaces. Ele captura a página pelo seu próprio Chrome local e
entrega somente HTML/texto ao Produto IA para processamento.

A captura NÃO salva cookies, senhas, tokens ou o perfil do Chrome.

PASSO 1 — NO WINDOWS LOCAL

Baixe/descompacte este projeto no computador e abra PowerShell/CMD na pasta
produto_IA.

Primeira vez:

  py -m venv .venv-local
  .venv-local\Scripts\activate
  pip install -r requirements.txt
  python -m playwright install chromium

Capturar o produto:

  python -m src.local_browser_capture "URL_DO_MAGALU" --output magalu_capture.json

O Chrome abrirá. Espere a página do produto carregar. Depois volte ao terminal
e pressione ENTER. Será criado magalu_capture.json.

Também existe o atalho:

  capturar_magalu_local.bat "URL_DO_MAGALU"

PASSO 2 — NO CODESPACES

Envie magalu_capture.json para a pasta produto_IA (ou data/local) e rode:

  python -m src.main "URL_DO_MAGALU" --local-capture magalu_capture.json

Exemplo:

  python -m src.main "https://www.magazineluiza.com.br/..." --local-capture magalu_capture.json

Você também pode acrescentar a categoria:

  python -m src.main "URL_DO_MAGALU" PROCESSADOR --local-capture magalu_capture.json

IMPORTANTE

- Uma captura corresponde a uma URL individual.
- Não existe paginação/crawling automático.
- O arquivo de captura não deve ser commitado no Git se não for necessário.
- Se a página local também estiver bloqueada, o Produto IA retorna erro em vez
  de usar "Não é possível acessar a página" como nome do produto.
