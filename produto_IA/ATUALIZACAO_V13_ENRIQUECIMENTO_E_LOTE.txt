PRODUTO IA / CRIABYTE — v13

Esta versão é cumulativa e deve ser aplicada diretamente sobre a v12.

NOVO — ENRIQUECIMENTO TÉCNICO
- Cadastro/análise continua 1 URL por vez.
- Pode complementar especificações ausentes quando a identidade do produto estiver confirmada.
- Identidade aceita: GTIN/EAN; marca + MPN; marca + modelo forte.
- Ordem de fontes: fabricante oficial -> TechPowerUp (GPU) -> PC-Kombo -> Geizhals.
- Não sobrescreve silenciosamente especificação existente.
- Divergências ficam em enriquecimentoTecnico.conflitos.
- Cada campo complementado registra fonte e URL.
- Se não houver identidade forte, não consulta fontes externas.
- Não tenta contornar CAPTCHA, 403, 429 ou bloqueios.

Uso:
python -m src.main "URL" --enrich

NOVO — RECALCULAR PREÇOS EM LOTE
- Recebe vários links em JSON, CSV ou TXT.
- Processa sequencialmente, uma URL por vez.
- Verifica somente Oferta: preço, preço anterior e disponibilidade.
- Não altera especificações técnicas.
- Retorna ATUALIZAR / SEM_ALTERACAO / ERRO por item.
- Gera a lista atualizacoes para o backend do CriaByte aplicar.

Uso:
python -m src.main --batch-prices ofertas.json --batch-output resultado.json

IMPORTANTE
O módulo de lote não grava diretamente no banco. O botão Recalcular preços do CriaByte deve consumir a lista de atualizações e aplicar no backend atual. Isso evita colocar token/credenciais administrativas dentro da Produto IA.
