CRIABYTE - CONTRATO PARA PÁGINA "DESCOBRIR HARDWARES COM IA"
Projeto IA v14.16

1. FRONTEND NÃO CHAMA PROJETO IA DIRETAMENTE
-------------------------------------------
Frontend -> Backend CriaByte -> Projeto IA

2. BACKEND CHAMA
----------------
GET  {PRODUTO_IA_URL}/descobrir-hardwares/fontes
POST {PRODUTO_IA_URL}/descobrir-hardwares
POST {PRODUTO_IA_URL}/descobrir-hardwares/detalhar

Header quando configurado:
X-API-Key: PRODUTO_IA_API_KEY

3. DESCOBRIR
------------
Request:
{
  "categoria": "PROCESSADOR",
  "marca": "Intel",
  "consulta": "Core i5",
  "pagina": 1,
  "limite": 20,
  "detalhar": true,
  "enriquecer": true,
  "noBrowser": false
}

categoria é obrigatória.
marca e consulta são opcionais.
limite: 1..50.

Categorias:
PROCESSADOR, PLACA_MAE, MEMORIA_RAM, PLACA_VIDEO, ARMAZENAMENTO,
FONTE, GABINETE, COOLER, VENTOINHA.

4. RESPOSTA
-----------
Cada item traz:
- identidade.metodo
- identidade.confianca
- identidade.chave
- identidade.marca
- identidade.modelo
- identidade.mpn
- identidade.gtin
- chaveComparacao
- payloadHardware
- especificacoesEncontradas
- camposEsperados
- camposAusentes
- camposObrigatoriosAusentes
- coberturaTecnica
- fontes
- origemPorCampo
- conflitos
- urlFontePrincipal
- fontePrincipal
- detalhesColetados
- erroDetalhamento
- preco = null

5. FILTRO DE JÁ CADASTRADOS É DO BACKEND
----------------------------------------
A página deve mostrar somente candidatos que NÃO existem.
O Backend deve comparar cada item antes de devolver ao frontend.

Prioridade:
1. GTIN
2. marca + MPN
3. marca + modelo
4. nome normalizado somente para revisão

chaveComparacao ajuda, mas o backend deve usar a lógica real do banco.

6. FRONTEND
-----------
Mostrar por candidato:
- Nome
- Marca
- Modelo
- MPN/GTIN quando houver
- ficha técnica completa da categoria
- cobertura técnica
- campos ainda ausentes
- fontes
- conflitos
- botão Adicionar
- checkbox para Adicionar selecionados

Não mostrar preço, pois este fluxo é somente Hardware.

7. ADICIONAR
------------
Ao clicar Adicionar:
- frontend envia candidato selecionado ao backend;
- backend refaz deduplicação;
- se continuar novo, cadastra Hardware;
- se já existir, não duplica e devolve aviso.

Para lote, validar item por item e usar transação/estratégia segura do backend.

8. DETALHAR INDIVIDUALMENTE
---------------------------
Se a listagem foi feita com detalhar=false, ou se um item precisa ser recarregado:

POST /descobrir-hardwares/detalhar
{
  "categoria": "PROCESSADOR",
  "nome": "Intel Core i5-9500",
  "url": "https://...",
  "fonte": "CPU_MONKEY",
  "marca": "Intel",
  "enriquecer": true,
  "noBrowser": false
}

10. SEGURANÇA
-------------
Nunca mandar ao frontend:

SURFSKY_TOKEN
segredos Railway

11. IMPORTANTE
--------------
Esta função é diferente de busca por URL de marketplace.

Descoberta Hardware:
fonte técnica -> Hardware sem preço

Busca Magalu/ML:
URL comercial -> Produto/Oferta/preço + Hardware relacionado
